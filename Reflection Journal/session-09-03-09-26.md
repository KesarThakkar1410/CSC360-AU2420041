# Session 9 - ASCII Trees, Testing and Remote Connections

## Session Reflection

In this session, I learned about ASCII trees, software testing, and remote computer connections. There was discussion about ASCII trees, which represent a tree using characters such as `/`, `\`, `|`, and `-`. I understood that printing a tree is simpler and can be useful for quickly checking or debugging the structure, while drawing a tree graphically provides a clearer visual representation but is more difficult to implement and requires more work.

Then there was a discussion about unit testing and acceptance testing. Unit testing focuses on testing individual parts of a program, such as methods or functions. Acceptance testing examines the entire system to determine whether it meets the user's requirements. This helped me understand that testing can happen at different levels depending on what we want to verify.

Another topic that we learned in this session was Test-Driven Development (TDD). In TDD, we first write a test that fails, then write the code to pass it, and finally improve the code while keeping the same functionality. I found this approach interesting because it makes testing a part of the development process rather than leaving it only for the end.

Then we discussed remote computer connection protocols such as RDP and SSH. RDP allows us to remotely access a Windows desktop, while SSH is mainly used to connect to a remote computer through the command line and run commands.

Overall, this session helped me understand how trees can be represented in different ways and how testing and remote connections are used in software development. I especially found TDD useful because it showed me a different way of approaching the coding process.
