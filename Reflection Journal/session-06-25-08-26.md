## Session Reflection

In today's session, I learned about Maven, Git workflow, threads, and how these concepts are connected to Java graphics. We first discussed the progression of our graphics work, from basic shapes like squares and triangles towards more complex objects such as trees. This helped me understand that the earlier drawing exercises prepare us for more complex graphics and concepts like recursion.

We also discussed an important Git practice: pulling the latest changes from the shared repository before starting new work. Although it takes only a few seconds, it can prevent merge conflicts and problems caused by working on an outdated version of the project.

The main topic for today's session was Maven and the `pom.xml` file. I understood that Maven manages the build process and project dependencies, while `pom.xml` contains the information Maven needs about the project and its required libraries. I found the dependency management part particularly useful because Maven can automatically download the required libraries instead of us having to add JAR files manually.

Then we discussed processes, threads, and thread safety. We connected these concepts to Swing and learned about the Event Dispatch Thread, which handles GUI operations. If multiple threads try to modify the same graphical content at the same time, it can result in incorrect or incomplete output. This helped me understand why Swing follows a specific approach for handling GUI operations.

The discussion also helped me remember the concepts from Operating Systems, where I had studied processes and threads. Seeing those concepts applied to an actual Java application made them easier to understand from a practical perspective.

Overall, this session helped me see that tools like Maven and concepts like thread safety are not separate from graphics programming. They are part of building reliable and well-organised applications. My main takeaway was that understanding why certain programming practices are required makes them much easier to remember and apply.
