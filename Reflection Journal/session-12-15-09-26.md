# Session 12 - Project Setup and Initial Development

**Session Date:** 15/09/26
---

## Session Content

Session 12 was mainly focused on starting our CSC360 group project. Our group was assigned to write a JavaFX program with a custom splash screen using FXML.               

We first discussed the project requirements and planned the application's basic flow. The application would start with a splash screen, then transition to the main notes application. We set up the JavaFX project and created the initial folders and files required for development on GitHub.

We also went through the basic role of FXML, Java classes, controllers, and JavaFX components. We then began creating the splash screen in FXML and added basic elements, including the application logo, name, version, and greeting. We tested the initial structure to make sure the FXML was loading correctly.

## What Else I Remember

I remember that the splash screen initially looked like mainly a design component, but while planning it, we realized that it would also have to connect with the application logic. We therefore discussed how it would eventually lead to the main notes screen.

Since this was a group project, we also made sure everyone understood the basic application flow before moving on to the major implementation in the next session.

## Visual Observations

The first version of our splash screen included the basic elements: the logo, application name, version, and greeting. It was not the final design, but it helped us establish the structure that we would build on later.

## Code / Implementation Done

We set up the JavaFX project and created the initial FXML structure. The basic splash screen interface was implemented, and the FXML was integrated into the project structure so we could test it.


## What I Understood Well

I understood the purpose of FXML more clearly through this project. Instead of putting the complete interface directly into Java code, FXML allowed us to define the visual structure separately, while the Java code would handle the application's behavior.

I also understood why planning the application flow before implementing the features was important, especially for a group project.

## What I Found Challenging

The main challenge was understanding how the FXML file, controller, and Java application were connected. Since there were different files involved, it initially took some time to understand where different parts of the application belonged.

## Connections to Prior Sessions

This session is directly connected with the JavaFX and FXML concepts covered earlier in the course: CSC360. The project gave us an opportunity to apply those concepts to a real-world application rather than only working with small examples.

## Real-World Applications Explored

Splash screens are commonly used in applications to provide users with feedback while the application loads. Similarly, separating the interface from the application logic makes larger applications easier to organize and maintain.

## Key Takeaways

1. FXML helps separate the user interface from the Java application logic.
2. Planning the application flow makes development easier.
3. Understanding the connection between FXML and controllers is important for JavaFX development.
4. A good initial project structure helps a group work more efficiently.
