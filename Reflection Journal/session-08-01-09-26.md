## Session Reflection

In today's session we started with discussing about our group project, where we created a GitHub repository and added our team members. It was useful to actually apply the Git and version control concepts we had discussed in earlier classes instead of only learning them theoretically.

Then we discussed about matrices and systems of linear equations. We discussed row vectors and column vectors with examples, which made the difference between them easier for me to understand. We also learned about some Java libraries, such as Apache Commons Math, EJML, and ND4J, that can be used for mathematical operations involving matrices. This also helped me see another practical use of Maven, since these libraries can be added as project dependencies.

Another interesting part was the discussing about why a stack can be more suitable than a queue for operations such as erasing or undoing actions. The last-in-first-out nature of a stack makes it useful when the most recent action needs to be reversed first.

We also looked at a JavaFX example where circles could be created using a right-click and connected with arrows. This helped me connect mouse listeners with graphical interaction, since the program needs to detect where the user clicks and respond accordingly.

Towards the end of the session, we discussed on how to check whether a point lies inside a circle using the distance formula. I liked this part as it connected the mathematical concepts we learned with actual graphics programming. Overall, the session showed me how mathematics, data structures, event handling, and Java graphics can all work together in one application.
