Then, we moved to Java graphics and focused on how a basic Swing application is structured. One thing that became clear to me was the relationship between JFrame and JPanel. Previously I thought about these components somewhat separately, but today's discussion helped me understand their actual roles. JFrame is the main window of the application, while JPanel  is placed inside it and gives the area where we can draw. Once the panel is created, we can override paintComponent(Graphics g) to control what appears on it. Calling super.paintComponent(g) is also important because it clears the previous contents before new drawings are rendered.
We then discussed some Object-Oriented Programming concepts that are useful when working with Java graphics. The idea of inheritance became clearer when we looked at how a subclass can extend a more general parent class. Instead of repeating common properties and methods, the subclass can reuse them and add its own behavior. We also discussed anonymous classes, which I found interesting because they allow us to define a small piece of functionality without creating a separate named class. This seems especially useful when working with event handling in GUI programs.
The geometry part of the lecture helped connect programming with coordinate-based calculations. We looked at how a rectangle can be drawn when two opposite points are given. The starting x and y coordinates can be determined using the smaller values, while the width and height come from the difference between the two points. This made me realize that even something as simple as drawing a rectangle requires some logical thinking about coordinates. We also worked with triangles, where three points are needed. The important part was making sure that the points do not fall on the same straight line, otherwise they would not produce a proper triangle.
Towards the end, we went over some of the basic Java code used in these examples, including imports, class declarations, access modifiers, the main method, and naming conventions.
