## Session Content

This session introduced us to a new topic in the course, which was digital image processing. We began with how computers analyse images and how different techniques can be used to improve their quality or identify important details.

The first topic discussed in class was image contrast. I understood that contrast refers to the difference between the lighter and darker parts of an image. When an image has high contrast, objects are easier to distinguish from their background. While, low contrast can make an image look dull, and it becomes difficult to identify different objects clearly.

We then discussed about image histograms. A histogram shows how pixel intensity values are distributed in an image. In an 8-bit grayscale image, these values range from 0 (black) to 255 (white). By looking at the histogram, we can understand whether an image is too dark, too bright, or has low contrast. We also learned about histogram equalization and it helps improve contrast by spreading the pixel intensity values across a wider range. 

Another important topic discussed in class was spatial filtering and convolution. We learned that a small matrix called a kernel moves across an image and performs calculations using the surrounding pixel values. Different kernels produce different results. For example, a Gaussian filter is used for blurring and reducing noise, a median filter helps remove unwanted noise, and Sobel and Laplacian filters are used for detecting edges. Sharpening filters help make details and boundaries more noticeable.

Then we discussed edge detection and segmentation. Edge detection helps identify areas where there is a sudden change in pixel intensity, which usually indicates the boundary of an object. We learned about Sobel, Prewitt and Canny edge detectors. The Canny method involves multiple steps, including reducing noise, finding gradients, thinning edges and selecting stronger edges. These techniques help a computer identify different regions and objects in an image.

## Real-World Applications Explored

Image histograms are useful in photography because they help photographers understand whether an image has the correct exposure. Cameras and editing applications such as Photoshop and Lightroom provide histograms so that users can check the distribution of light and dark areas in their photographs.

Image filtering and edge detection are also used in many real-world applications. For example, medical imaging systems use these techniques to make boundaries and details in scans easier to identify. Self-driving vehicles use image processing to detect road boundaries, lane markings and nearby objects. Document scanning applications can also use thresholding techniques to separate text from the background and make scanned documents clearer.

## Key Takeaways

1. Contrast helps distinguish objects from their backgrounds. A good contrast level makes important details and boundaries easier to identify.

2. An image histogram shows the distribution of pixel intensity values from 0 to 255 and helps us understand the brightness and exposure of an image.

3. Histogram equalization improves image contrast by redistributing intensity values using the cumulative distribution function. Otsu's method helps automatically select a threshold to separate different regions.

4. Convolution uses a small matrix called a kernel to perform calculations on neighbouring pixels. Different kernel values can be used for blurring, noise removal, sharpening and edge detection.

5. Edge detection identifies sudden changes in pixel intensity that usually represent object boundaries. The Canny method uses multiple steps to produce clearer and more accurate edges.
